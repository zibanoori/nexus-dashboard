# 🌟 Nexus Dashboard

A clean, modern, and responsive admin dashboard built with pure HTML, CSS, and JavaScript. Features a fully collapsible sidebar with smooth animations and a beautiful card-based layout.

## ✨ Features

-   **Fully Collapsible Sidebar:** Smooth toggle animation that completely hides the sidebar to maximize workspace.
-   **Floating Toggle Button:** Smart floating button that stays accessible even when the sidebar is hidden.
-   **Responsive Card Layout:** Beautiful stat cards with hover effects and color-coded icons.
-   **Pure Frontend:** No frameworks or libraries required; lightweight and fast.
-   **Font Awesome Integration:** Professional vector icons for a polished UI.

## 🛠️ Tech Stack

-   HTML5
-   CSS3 (Flexbox, Grid, Transitions)
-   Vanilla JavaScript
-   Font Awesome 6

## 🚀 Getting Started

1.  Clone the repository:
    ```bash
    git clone https://github.com/zibanoori/nexus-dashboard.git
    ```
2.  Open `index.html` in your browser.
